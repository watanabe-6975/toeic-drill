## 用語

| 用語 | 意味 | 例え |
|---|---|---|
| 静的Webアプリ | サーバーで計算せず、HTML・JS・CSS のファイルだけで動くアプリ | 印刷して配るだけで使える問題集。採点係が要らない |
| PWA | ホーム画面に置けて、通信なしでも動くWebアプリ | Webページに「アプリの服」を着せたもの |
| Service Worker | ファイルを端末に保存し、通信なしでも開けるようにする仕組み | 手元に置いた問題集のコピー。本社（サーバー）に行かなくても読める |
| localStorage | ブラウザの中に記録を保存する場所 | その端末だけの手帳。別の端末とは共有されない |
| 間隔反復 | 間違えた問題を、間をあけて何度か出し直す学習法 | 忘れかけたころにもう一度見る単語カード |
| speechSynthesis | ブラウザの音声読み上げ機能 | 端末に住んでいる朗読係 |
| GitHub Pages | GitHub のリポジトリをそのままWebサイトとして公開する仕組み | 本棚に置いた本を、そのまま店頭に並べてくれるサービス |
| force push | GitHub 側の記録を手元の記録で上書きする push | 綴じた書類を新しい版に差し替える。古い版は戻せない |
| 機械点検 | プログラムで問題データの不備を見つけること | 答案の空欄や二重解答をスキャナーで探す。中身の正しさまでは見ない |
| 版番号（バージョン） | アプリの更新ごとに上げる番号 | 問題集の「第3版」の表記 |
